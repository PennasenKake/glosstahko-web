Instagram-nostojen kuvat (valinnaisia).

Tallenna noston kuva tähän tiedostonimellä `TUNNISTE.jpg` (tai .webp / .png), missä TUNNISTE on
noston osoitteen loppuosa (instagram.com/glosstahko/p/TUNNISTE/). Esim. `DehljGiN8mO.jpg`.
Kortti käyttää kuvaa automaattisesti. Ilman kuvaa kortissa on logon lehvä.

Vinkki: rajaa kuva neliöksi tai 4:3-kuvaksi ja pienennä leveyteen 800 px (alle 100 kt), niin sivu pysyy nopeana.
Kuva on Siirin oma, joten sen käyttö omalla sivulla on ok. Ei Metan pyyntöjä: kuva tulee omalta palvelimelta.
